Contracts are saved in a private GitHub repository that only you (and people you invite) can see. Connect it once on each device.

How do I get an access token?
  1. Open github.com/settings/personal-access-tokens/new.
  2. Name it TMC dashboard and pick an expiry (e.g. 1 year).
  3. Under Repository access, choose Only select repositories and select tmc-contracts-data.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it above.
